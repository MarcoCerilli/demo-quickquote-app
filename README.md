# QuickQuote Pro | Agency Estimator & Margin Visualizer

Web app modulare per software house e agenzie web: calcolo ore sviluppo, tariffe orarie, moltiplicatore complessità e marginalità netta.

## 🚀 Guida Rapida Deploy su Vercel

Questo progetto è un'applicazione React + Vite + Tailwind CSS autonoma e indipendente al 100%, pronta per essere caricata su una repository GitHub dedicata e pubblicata su Vercel.

### 1. Esegui in Locale
```bash
npm install
npm run dev
```

### 2. Build di Produzione
```bash
npm run build
```

### 3. Pubblicazione su GitHub & Vercel
1. Crea una nuova repository su GitHub: `https://github.com/new` (es. `quickquote-webapp-demo`).
2. Inizializza Git e carica il codice:
```bash
git init
git add .
git commit -m "feat: initial commit for QuickQuote Pro | Agency Estimator & Margin Visualizer"
git branch -M main
git remote add origin https://github.com/TUO-USERNAME/quickquote-webapp-demo.git
git push -u origin main
```
3. Vai su [Vercel](https://vercel.com/new), importa la repository e clicca **Deploy**.
