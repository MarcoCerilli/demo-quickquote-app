# QuickQuote Pro | Studio & Software House Estimator

Strumento professionale di preventivazione tecnica ed economica per software house, agenzie web e studi digitali. Consente la scomposizione analitica per fasi di sviluppo (WBS), la calibrazione delle ore stimate, il computo fiscale (IVA ordinaria, forfettario, reverse charge), la generazione del documento formale per il cliente (stampabile in PDF A4) e l'analisi di redditività interna con calcolo del punto di pareggio (break-even).

---

## 💼 Caratteristiche Principali

- **WBS per Fasi di Sviluppo Reali**:
  - *Fase 1*: Discovery, UX/UI Design & Prototipazione Figma
  - *Fase 2*: Sviluppo Frontend & Esperienza Utente (Core Web Vitals)
  - *Fase 3*: Backend, API REST & Architettura Dati
  - *Fase 4*: Integrazioni di Terze Parti (Stripe, CRM, Webhook)
  - *Fase 5*: Collaudo, Sicurezza (OWASP) & Conformità GDPR
  - *Fase 6*: Rilascio Cloud CI/CD, Formazione & 60gg Garanzia
- **Attività Personalizzate**: Possibilità di aggiungere voci su misura a ciascuna fase con ore dedicate.
- **Preset di Progetto Reali**: Caricamento immediato di stime per Portali Immobiliari, Siti Corporate B2B, E-Commerce avanzati e Web App SaaS.
- **Inquadramento Fiscale**: Gestione Imponibile, eventuale sconto commerciale concordato, IVA al 22%, Regime Forfettario o Reverse Charge.
- **Piano di Pagamento (SAL)**: Ripartizione acconto / tranche intermedie / saldo a collaudo.
- **Documento Formale Cliente (Stampa / PDF A4)**: Layout pulito, elegante e formale pronto per la sottoscrizione del committente con `@media print` ottimizzato.
- **Bozza Email Formale**: Copia rapida negli appunti del testo commerciale per il cliente.
- **Cruscotto Riservato di Redditività**: Calcolo costo vivo del personale, margine di contribuzione (%) e tariffa oraria di break-even.

## 🚀 Guida Rapida

### 1. Esegui in Locale
```bash
npm install
npm run dev
```

### 2. Build di Produzione
```bash
npm run build
```

### 3. Deploy su Vercel
Carica la repository su GitHub e importala direttamente su [Vercel](https://vercel.com/new). Il framework Vite verrà riconosciuto automaticamente.
